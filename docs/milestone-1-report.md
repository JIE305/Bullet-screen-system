## 修复记录

- 覆盖层边界从测试窗口切换后不更新：启动会话时强制读取并应用目标 HWND 边界。
- 覆盖层落到目标窗口后方：统一采用 `showInactive → setAlwaysOnTop(true) → moveTop()`。
- 重启时残留弹幕闪烁：停止时先透明隐藏，再销毁整个覆盖层 Renderer；新会话等待样式就绪后显示。
- npm 缓存无权限：安装脚本优先使用 Corepack，并提供项目本地 pnpm 回退，不要求写全局 npm 缓存。

## 边界

只支持窗口化和无边框窗口；不支持独占全屏、注入、绕过反作弊、账号、多用户或云部署。人工实际游戏、DPI 125% 与 30 分钟长时运行仍属于最终候选版本验收，而不是第 1 周链路缺口。
