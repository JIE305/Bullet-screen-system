## 验收中发现并修复的问题

首次真实运行时，HTTP 健康检查正常，但 WebSocket 升级返回 404。根因是 Uvicorn 的基础安装未包含 WebSocket 协议实现。现已把 `websockets>=13,<16` 加入后端运行时依赖，并通过真实进程集成和 Electron 冒烟复验。

从内置测试链路切换到所选窗口时，覆盖层曾复用测试窗口的旧边界。根因是无边界参数时 `ensureOverlay` 不更新已有窗口，同时测试窗口引用在未关闭时被清空。现已加入认证的 HWND 边界查询、250 ms 变化轮询、切换时强制更新和正确的测试窗口生命周期。

覆盖层调用 `moveAbove(sourceId)` 后可能从 Windows 置顶层回落，导致弹幕出现在目标窗口后方。现已统一使用“`showInactive` → `setAlwaysOnTop(true)` → `moveTop()`”恢复层级，并在创建、复用和边界变化时执行；自动冒烟同时断言覆盖层可见、置顶且不可聚焦。

会话停止后再次启动时，覆盖层曾短暂闪现上一会话的弹幕。根因不是 Python 帧队列，而是复用的覆盖层 Renderer 仍保留旧 `messages` 和删除定时器；窗口隐藏期间 Chromium 还可能暂停动画和计时。现已增加内部重置 IPC，在停止和新会话显示前同步清空消息、取消全部定时器，并用队列代次防止旧回调影响新消息；主进程同时按当前 `session_id` 过滤迟到的旧会话事件。

首次修复后仍可能看到一次极短闪烁，因为主进程发送重置 IPC 后立即显示隐藏窗口，Windows 有机会先合成覆盖层保存的旧纹理，Renderer 随后才处理清空。现改为会话级覆盖层：停止时先将透明度设为零并隐藏，再销毁整个 BrowserWindow/Renderer；新会话只创建隐藏且透明度为零的新窗口，页面加载完成后才恢复透明度并显示，从根源上杜绝旧 DOM 和旧合成纹理跨会话复用。

新增全局弹幕可读性设置：字体组合、14～48px 字号、400/500/600 字重、文字颜色和背景不透明度可在控制台右侧抽屉实时预览，并同步更新活动覆盖层。设置经主进程校验后原子保存到 Electron 用户数据目录；新覆盖层完成样式应用前保持全透明。自动冒烟已验证活动弹幕即时更新以及覆盖层销毁重建后的样式延续。

Windows 控制窗口现已全局移除 Electron 默认应用菜单，按 Alt 不会重新唤出；弹幕样式抽屉隐藏了滚动条轨道，但继续保留滚轮、触控板、键盘与焦点滚动能力。

“最近事件”现作为当前应用周期内的轻量收件箱：新事件置顶、按 `event_id` 去重并限制为 30 条，可筛选全部/弹幕、复制完整摘要、移除单条及按当前筛选清空。事件管理只修改控制台本地记录，不影响覆盖层、后端或事件协议；剪贴板写入由安全 preload 转交主进程，并拒绝空值与超过 8192 字符的内容。

## 已知限制

- 当前识别器只返回测试文本，不进行 OCR。
- 配置、会话和事件只保存在内存，重启后清空。
- 覆盖层已支持基础移动和缩放跟踪；窗口最小化、关闭检测及跨 DPI 的完善仍属于第 3 周。
- 真实窗口的 ROI 编辑、预处理、去重、冷却和规则模板属于第 2 周。
- pytest 有一条来自 FastAPI/Starlette 测试客户端依赖的弃用警告，不影响运行结果。
